# Bird detection alert

`bird-alert.mp3` is a laughing kookaburra call: six seconds of audio
(6.034 seconds including MP3 frame padding), mono, 44.1 kHz, 192 kbps MP3.

- Source: [kookaburra](https://freesound.org/people/soundofsong/sounds/841979/)
- Creator: soundofsong
- Source description: “A laugh from a kookaburra.”
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/),
  verified on the source page.
- Downloaded the high-quality MP3 preview linked in that page:
  <https://cdn.freesound.org/previews/841/841979_9782868-hq.mp3>
- Changes: retained the first six seconds of the 6.375-second recording,
  raised gain by 15.8 dB (decoded peak approximately -6.3 dBFS), added a
  10 ms fade-in and 150 ms fade-out, stripped inherited replay-gain metadata,
  and re-encoded to MP3 for compatibility with older iPads.
- Retrieved November 22, 2026.

The file is bundled locally, so playing the alert makes no third-party request.
Attribution is retained here for provenance even though CC0 does not require it.
